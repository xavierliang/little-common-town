# Browser playtest checklist

- Verify actual WebGL model rendering, camera, resident selection, selected labels, and result replay.
- Complete all seven days using two-action limits and daily result dialogs.
- Exercise aid, firm funding, automation, and recurring support.
- Verify progress survives reload and same-seed retry returns to the same initial state.
- Verify rapid repeated action/settlement input does not bypass limits.
- Enter and leave sandbox without losing challenge progress.
- Test desktop and narrow/mobile viewport layouts; check controls and results remain reachable.
- Capture first view, decision, resident interaction, daily outcome, final outcome, and mobile view.
- Assess clarity and enjoyment separately from functional correctness.
