# 小小共生镇 · Little Common Town

基于 React、Three.js 的本地 3D 故事试玩。v7 默认进入「面包出炉以后」：阿禾与小满在七天里分配机器腾出的两小时。原有小镇挑战和自由实验沙盒保留在菜单中，各自存档保持独立。

本实验分支另有「搬运与供给规则实验」：观察人物实际搬运、烘烤、送餐与进食，再移动设施比较供给距离与瓶颈。打开 `/?mode=experiment`，或从首页与手册进入。详见 [规则、操作与模型比较](RULES-EXPERIMENT.md)。该实验尚未发布到线上 Site，实际画面和手机交互待验收。

## 本地运行

需要 Node.js 22 和 npm。

```sh
npm ci
npm test
npm run build
npm run dev -- --host 127.0.0.1 --port 5180
```

浏览器打开 http://127.0.0.1:5180 。3D 场景需要 WebGL；模型已包含在 `public/models/`。应用没有后端，不需要账号或 API Key。存档保存在浏览器 localStorage。

## 面包坊故事试玩

四次决策覆盖第 1–2、3–4、5–6 和第 7 天。选择角色，安排各自的两小时，查看整轮时间和产出预估后确认；确认前可以撤销。角色明确拒绝的安排不可选择。结算采用确定性模型，动画速度不影响账目。

终局记录个人时间、送货、额外面包、工资和店铺资金，不给道德评分。可从固定检查点重试并与本次会话的上一结果比较。菜单支持导出和导入故事进度。

v7 修正阿禾与小满的下巴、笑容及颈部衔接，并更新两张头像；环境、镜头、存档和经济规则保持不变。新版使用带内容哈希的资产路径，旧路径保留用于既有版本兼容。

## 原有小镇七天挑战

七天内让居民累计吃到 100 餐、完成 40 班工作，并在最后保留至少 ¥4 应急金。每天最多两次行动，然后结算当天。

- 点选居民，定向救助 ¥1.80。
- 投入 ¥6 企业周转金，支持招聘和工资。选中企业时资金进入该企业，议事面板操作时选择现金较少的企业；岗位仍由需求决定。
- 投入 ¥10 自动化，提高生产率；可能减少劳动需求。
- 开启或暂停每人每日 ¥0.70 的普惠补助。

结算后播放工作、购物和归家的 4.5 秒结果回放，并显示每日统计。结束时可以重试相同起点。挑战条件用于小游戏的预算分配谜题，不代表现实政策结论。

## 沙盒

沙盒提供自由运行、调速、账本、政策与存档功能，没有七天过关目标。沙盒和挑战使用不同存档键；返回挑战可继续原来的进度。
